# 网页剪藏到飞书多维表格（Chrome 扩展）

一个类 Cubox 的浏览器剪藏插件：点击扩展图标，在网页右上角打开剪藏浮层。先选图片、编辑提示词或内容摘录，检查本地推荐分类，必要时调整，保存到自己的飞书多维表格。

## 1.7.4 X 视频与站内切换修复

- X 播放器尚未生成视频标签时，也会通过原帖视频封面和页面媒体数据识别可保存的 MP4，并默认优先最高画质。
- 兼容 X 新版嵌套媒体结构和 `media_key`，保留短暂重试；仍未加载时会给出可操作的提示。
- 从一条 X 帖子站内切换到另一条后，第一次点击插件即重新读取当前帖子，不再关闭旧面板或误报需要刷新页面。
- 同一帖子在普通详情页与 `/video/1`、查询参数等地址形式之间切换时，仍视为同一来源。

## 1.7.3 自定义同级分类

- 设置页在每个提示词类型下新增「添加同级分类」，可把“创意视频”等新分类添加到“人物情绪 / 影视效应”等相同层级。
- 从飞书同步后可直接选择尚未绑定的新子表；选择「视频提示词-创意视频」时会自动填写“创意视频”，并读取主分类、风格和模型。
- 分类卡片支持删除；所有新增与删除均在点击「保存设置」后才正式用于剪藏。

## 1.7.2 更大的提示词预览区

- 桌面端剪藏浮层最大高度由 740px 增至 900px，提示词较长时可一次看到更多内容。
- 新增高度优先分配给「提示词 / 内容摘录」编辑框；较矮或较窄的窗口仍自动贴合可用空间。

## 1.7.1 视频支持所有分类

- 视频附件跟随所选分类保存，不再限于成品提示词。
- 目标表按优先顺序使用附件字段「视频」「成品视频」「参考视频」，缺少字段时提示具体表名。30MB 上限不变。

## 1.7.0 通用视频与素材预览

- 移除视频平台域名白名单，识别网页 video/source 的 HTTP(S) 地址，不要求 .mp4 后缀；实际文件仍须为 MP4。临时 blob、分段流和受保护视频不保证支持。
- 抖音按作品 ID 排除推荐视频，小红书单笔记播放器支持读取；通用页有多个视频时提供选择。
- 视频上限 30MB（30×1024×1024 字节），声明超限立即拒绝，未知大小读取超限即停止，上传入口再次校验。20–30MB 仍分片上传。
- 第一页编辑提示词、选择图片视频，第二页确认自动推荐的分类后保存。
- 封面大预览恢复并加大，候选缩略图放大，选中图片显示紫色描边和“已选”标记。

## 1.6.3 子表选择与模板更新

- 更新设置页模板链接。
- 选择目标子表后先保留绑定；分类选项或字段类型不匹配时提示原因，不再回退旧名称。自动读取失败时保留原风格和模型，实际剪藏仍校验目标表字段。

## 1.6.2 子表绑定修复

- 切换子表时使用新表的主分类选项；不能唯一对应时保留目标表，提示补选主分类后保存。
- 更新分类设置时保留卡片展开状态。

## 1.6.1 设置页修复

- 侧栏高亮跟随栏目链接切换，支持直接链接和浏览器前进、后退。
- 分类与模型下拉框统一圆角、浅色背景和紫色聚焦样式。

## 1.6.0 本地分类推荐

- 只根据提示词文字匹配现有分类、风格和模型，不分析图片或视频，不调用模型接口，无需密钥。
- 推荐结果显示在保存按钮上方；主分类明确后可直接保存，不确定时手动选择，风格和模型可留空。
- 手动选择不会随提示词编辑被覆盖；点击「重新识别」可重新匹配。设置中可关闭自动推荐。
- 这是本地规则匹配，不能替代大模型的语义理解。若需要飞书 AI 补充标签，可在入表后另行配置。

## 1.5.0 视频剪藏

- 支持 AhaPrompt 作品页、Meigen 视频页和 X / Twitter 原帖中的 MP4 视频；识别主作品，排除推荐与引用视频。
- 第一步新增视频预览、清晰度选择和「同时保存成品视频」开关；1.6.0 起仅按提示词推荐分类，视频附件仍仅支持「视频提示词 → 成品提示词」。视频封面可在图片栏选中，单独写入封面字段。
- Meigen 按 Video 标签读取视频提示词，排除 Image 参考图提示词。AhaPrompt 只取独立提示词正文，X 保留原帖文字。
- 目标表须有名为「成品视频」的附件字段。当前用户的成品提示词表已添加；其他表格需自行添加。插件不会自动改表结构。
- 视频最多 200MB，超过 20MB 自动分片上传；先上传视频与封面，再创建记录。失败时保留草稿，提示原因；同一草稿重试使用同一个记录请求标识，减少重复记录。
- 保存过程中请保留来源网页和浏览器；可以收起浮层，但刷新或关闭网页会结束当前草稿。X 未识别到视频时，先播放原视频，再点「刷新视频」。仅支持当前可读取的完整 MP4，不支持 DRM 或只有分段播放列表的视频。
- 更新：解压安装包并覆盖原扩展目录，在扩展管理页点重新加载，再刷新已打开的网页。最低 Chrome 110。

验证：三个站点的页面采集、实际扩展内的预览/选择/保存、异常视频拒绝、分片上传、失败不写记录、取消视频、移动窄屏和即梦回归。自动化保存使用模拟飞书接口；本任务此前已实际上传 16.6MB 的 X 视频至成品提示词表。

- 即梦全站只读取独立提示词区域，首页作品弹层也不会回退到整页正文；无法可靠识别时留空提示。

## 1.4.0 更新

- 飞书单选字段写入字符串，多选字段写入数组；schema 类型异常或非法选项会明确阻止保存，不静默丢字段。

## 功能

- **正文提取**：X / Twitter 帖子详情按链接中的帖子 ID 定位原帖，只读取原帖正文，保留参数和换行。普通文章使用 Mozilla Readability 与正文容器，弹出窗中可编辑。
- **封面图选择**：自动收集 `og:image` + 页面最多 8 张大图作为候选，固定高度预览与横向缩略图，点选后可切换或取消。
- **网页内剪藏**：图片、提示词和分类摘要同屏，分类明确可直接保存，需要时展开分类与模型选项；底部按钮固定，支持返回编辑、关闭再打开保留当前页面草稿。
- **飞书多维表格**：自动获取 `tenant_access_token` 并缓存，封面图先上传为附件（`file_token`），再写入一条记录。
- **免登录调用**：使用飞书开放平台「企业自建应用」凭据，App Secret 仅保存在本机浏览器存储中。

### 更新到 1.1.4

修复即梦等 AI 作品详情页剪藏时，右侧「图片提示词」区块丢失的问题。原因是此类页面的提示词不在文章正文容器里，而在「标签 + 相邻正文」的旁栏结构中，且面板内容由前端脚本延迟渲染，点击图标瞬间提取常常为空。

现在的处理：提取脚本会在约 4 秒内多次读取页面，保留信息量最大且稳定的结果；同时识别「图片提示词 / Prompt」等标签及其紧邻正文。识别为纯文字标签并要求可见渲染，普通文章页面行为不变。

对于 AI 作品详情页这类提示词就是页面主要文字内容的场景，摘录会收敛为**提示词 + 生成参数**（如模型「图片 4.7」、比例「9:16」），去掉头像、作者名、操作按钮（做同款/用作参考图/更多等）噪声。详情从信息流点开（全屏弹窗）时，只统计弹窗内部的文字，背后的信息流推荐完全排除；如果提示词只是长文里的一小部分（如教程文章引用了一段 prompt），则保留全文并补齐缺失的提示词，正文不会误删。

更新后在扩展管理页点击「重新加载」，并刷新需要剪藏的网页。

### 更新到 1.1.2

修复短帖正文被推荐流替换的问题。X / Twitter 的帖子详情按原帖时间戳链接匹配帖子 ID，只采集该帖正文，排除回复、引用帖和趋势栏；原文如 `--sref 200353321` 会原样保留。动态页面最多等待约 4 秒，仍未加载到原帖就留空并说明原因。折叠长文会提醒先在原帖展开。

普通文章不再因正文不足 80 字而替换为更长的页面内容，也不再把整页文字作为最终兜底。

## 飞书侧配置（一次性）

### 1. 创建应用并授权

1. 打开 [飞书开放平台](https://open.feishu.cn/app) → **创建企业自建应用**
2. 在应用后台添加以下权限：
   - `bitable:app`（多维表格读写）
   - `drive:file:upload` 或 `docs:file:upload`（上传附件）
3. **发布应用版本**（未发布的应用无法调用 API）
4. 在 **凭证与基础信息** 页复制 `App ID` 和 `App Secret`

### 2. 准备多维表格（三选一，推荐 A）

插件会把剪藏记录写入含以下 5 个字段的数据表（**字段名必须完全一致**）：

| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 标题   | 文本     | 网页标题，可编辑 |
| 内容   | 文本     | 正文摘录（Markdown），提取失败时可留空 |
| 链接   | 超链接   | 原网页 URL |
| 封面   | 附件     | 封面图片文件 |
| 分类   | 多选     | 剪藏弹窗中选择的分类类型（可选） |
| 使用模型 | 单选   | 剪藏弹窗中选择的模型（可选，需表格先建好对应选项） |

#### 方式 A：使用官方模板，创建副本（推荐）

1. 打开[新版剪藏模板](https://zk5ckzju3h.feishu.cn/base/ZwXJb3TZVazIuvsqaVacB0Kani2?table=tbl6zpQtXascLo2Y&view=vewV3O5Sti)
2. 右上角 **「...」→「创建副本」**，副本会保存到你自己的云空间，包含全部 9 个字段：分类、工作台分类、内容、可直接复制提示词、封面、链接、标题、风格码、使用模型。
3. 在**副本**中选中「剪藏」数据表，复制浏览器地址栏中的完整链接，填到扩展设置页，再按下文授权应用访问副本。

插件填写上表中的 6 个剪藏字段。「工作台分类」是单选字段，在飞书中整理，选项为古风武侠、都市现代、赛博科幻、光影氛围、运镜构图。「可直接复制提示词」「风格码」是带 AI 配置的文本字段，由飞书侧处理，插件不会填写；风格码用于 MJ。复制后请检查飞书侧 AI 配置和运行状态。自定义分类或模型时，请在副本中同步添加对应选项，并保留插件写入字段的名称与类型。

已有旧副本不会随模板更新；需要新版全部字段时，请重新复制模板并更新扩展设置。下方脚本和 CSV 仍提供基础 6 字段表格，需要完整 9 字段及 AI 配置请使用新版在线模板。

> ⚠️ 插件内置审查：直接填模板链接会被拦截（模板是发布者的只读母版，剪藏数据不能写进去）。必须先创建副本，用自己的副本链接。

#### 方式 B：运行脚本一键建表

需要电脑装有 Node.js（18+）：

```bash
cd template
# Windows CMD：
set APP_ID=你的AppID
set APP_SECRET=你的AppSecret
node create_bitable_template.js
# Windows PowerShell：
$env:APP_ID="你的AppID"; $env:APP_SECRET="你的AppSecret"; node create_bitable_template.js
```

脚本会自动创建名为「网页剪藏库」的多维表格，含「剪藏」数据表和上述 6 个字段（超链接/附件/分类多选/使用模型单选只有通过 API 才能直接建对，单选与多选的选项也已按默认清单建好），最后打印表格链接——把它复制到扩展设置页即可。

#### 方式 C：导入 CSV 模板

1. 新建一个空多维表格 → 左下角 **＋ 新增数据表** → **导入** → 选择本项目的 `template/剪藏表格模板.csv`
2. 导入后得到含「标题/内容/链接/封面/分类/使用模型」6 列的数据表，删掉那条示例行
3. 手动调整字段类型：把「链接」列改成 **超链接** 类型，把「封面」列改成 **附件** 类型，把「分类」列改成 **多选**（选项：生图提示词、视频提示词），把「使用模型」列改成 **单选**（选项：GPT2、bananaPro、MJ、seedream5Pro、seedream4.7、seedream3.1、seedance2.0、seedance2.5、minimaxH3、KelingO3；CSV 导入的列默认是文本，不改的话插件写入链接、封面、分类和模型会失败）
4. 把表格分享链接复制到扩展设置页

### 4. 授权应用访问表格

把该多维表格 **添加为应用的可用范围**：在多维表格右上角「...」→「更多」→「添加文档应用」，搜索并添加你创建的应用（否则 API 会报无权限）。

> 提示：模板副本同样需要执行这一步；方式 B 由脚本创建的表格默认应用可访问，通常可跳过。

### 3. 配置扩展

1. 在普通网页点击浏览器工具栏的扩展图标 → 网页浮层右上角 **设置图标**（或扩展右键菜单中的选项）
2. 设置页顶部内置了完整使用指引（含模板直达链接）：打开模板 → 创建副本 → 填副本链接；若已有表格可直接填
3. 填入 App ID、App Secret、你的副本多维表格链接（可粘贴完整链接，自动提取 token）、数据表名（副本默认表名为「剪藏」，可留空）
4. **分类与模型**：设置页「一级分类」每行一个类型（默认 `生图提示词`、`视频提示词`）；「二级模型」每行 `分类=模型1,模型2`（默认与常见生图/视频模型一致）。剪藏时类型可多选，模型单选；模型会写入表格「使用模型」单选字段
5. 保存

## 使用

1. 打开任意文章网页
2. 点击扩展图标 → 网页右上角出现浮层，自动提取标题、正文和封面候选
3. 第一步：横向浏览缩略图，选一张封面（可选），编辑标题和提示词 / 内容摘录
4. 点击 **下一步 · 选择分类** → 第二步选择分类（多选）和模型（单选），也可留空；点击 **保存到飞书**
5. 出现「灵感，收好了。」即成功，点击 **完成** 收起。重复打开同一页面的已保存浮层不会再次提交。
6. 已选封面但图片下载或上传失败时，不创建缺图记录，浮层保留错误原因和内容。可直接重试，或返回上一步点击「移除封面」后保存文字。
7. 点击「上一步」随时返回编辑；关闭浮层后再次点击插件图标继续当前草稿。浮层外仍可浏览网页，滚动网页加载更多图片后点击「刷新图片」。

## 常见问题

- **提示「这是模板表格链接」**：模板是发布者的母版，需先打开模板 →「...」→「创建副本」，把副本链接填到设置页。
- **「无法识别正文结构」**：页面结构特殊（登录墙/纯视频页），可手动在摘录框粘贴内容。
- **「写入记录失败(91403)」**：NOTEXIST —— 检查 app_token 与数据表名，以及应用是否被添加到该多维表格的可用范围。
- **「写入记录失败(1254030)」**：字段类型不匹配 —— 确认「封面」是附件字段、「链接」是超链接字段。
- **「此页面不支持剪藏」**：Chrome 商店、chrome:// 等浏览器内部页面受安全策略限制。
- **封面上传失败**：确认应用具备素材上传权限，发布了应用版本，并已被添加为目标表格的文档应用。「封面」字段必须是附件类型。
- **封面获取失败**：插件先直接下载图片，再尝试通过原网页下载。部分登录、防盗链或跨域受限的图片仍可能无法获取；错误会保留在弹窗中，可换图或取消封面后保存文字。
- **图片大小**：单张封面支持不超过 20MB；超出时会提示选择较小图片。
