01

配置指南

第一次使用？先在飞书侧完成下面 5 步，约 5 分钟，只需配置一次。

  1. 复制多维表格模板，创建自己的副本

    打开网页剪藏库模板 ↗，在右上角「…」中选择「创建副本」。名称可自定义，建议不加入多维表格空间，复制范围选「仅复制表格结构」即可。模板是只读母版，剪藏只能写入你的副本。

  2. 创建企业自建应用，开通三个权限

    打开飞书开放平台 ↗，点击「创建企业自建应用」，名称和描述随意填写。进入应用后，在左侧「权限管理」→「开通权限」中开通 bitable:app、bitable:app:readonly、drive:file:upload 三个权限。

  3. 发布应用版本，复制凭据

    权限开通后点击「创建版本」，版本号和更新说明随意填写，保存并确认发布——未发布的应用无法调用接口。发布后在「凭证与基础信息」页复制 App ID 和 App Secret，稍后填入下方「03 飞书连接」。

  4. 把应用添加为副本的「文档应用」

    打开你的多维表副本，右上角「…」→「更多」→「添加文档应用」，搜索刚创建的应用并添加，确保权限状态为「可编辑」。跳过这一步，保存剪藏时会报无权限。

  5. 回到本页填写并保存

    把副本地址栏的完整链接填入「02 收藏位置」，App ID 和 App Secret 填入「03 飞书连接」，点击底部「保存设置」。随后可在「04 分类与模型」点「从飞书同步选项」读取表里的风格与模型，确认后再保存一次，即可开始剪藏。

02

收藏位置

选择保存提示词的多维表格。

支持完整 /base/ 链接或 app_token；剪藏时按分类自动写入对应数据表，无需指定表。

使用说明：剪藏流程、三级分类与同步
  1. 首次配置（复制模板副本、创建飞书应用、授权访问副本）请按 「01 配置指南」 逐步完成，再把副本链接、App ID、App Secret 填入本页并保存。
  2. 打开要收藏的网页，点击插件图标：选择封面、编辑提示词，点击「下一步：确认分类」，检查本地推荐并调整分类、风格和模型，点击「保存到飞书」，记录会写入分类对应的数据表。

三级分类与数据表

  • 一级「提示词类型」：默认有生图提示词 / 视频提示词，也可点「添加提示词类型」自定义（如音频提示词）；类型名称写入各表的「分类」多选字段。
  • 二级「分类」：生图下分人物、环境、生物、海报；视频下分镜头画面、运镜方案、影视效应、人物情绪、成品提示词，也可添加“创意视频”等自定义分类。它决定记录写入哪张数据表，并以「前缀-分类」写入该表的「主分类」单选字段（如 生图-人物）。
  • 三级「风格」单选，写入「子分类」字段（如 古风、仙侠、动漫）；「使用模型」单选（如 MJ、seedance2.5）。各表可用的风格与模型略有不同，与模板一致。

同步与调整分类

  • 先保存连接配置，再点击「从飞书同步选项」。插件读取目标子表的风格与模型，并兼容「视频参数-…」的子表名称。
  • 需要全新一级类型时，点「添加提示词类型（一级分类）」，填写名称（如音频提示词）；新类型需在飞书子表的「分类」多选字段里先加上同名选项，再绑定该子表。要改名时，直接编辑该类型下的「类型名称」，改名后记得在绑定子表的「分类」字段里补上同名选项；也可删除不再使用的类型。
  • 需要新增与“人物情绪”等同级的分类时，在对应提示词类型下点「添加同级分类」，填写名称并绑定新增子表；也可删除不再使用的分类。
  • 展开分类卡片查看目标子表和主分类，点击标签上的 × 移除选项；同步后可以从下拉框添加表格已有选项。
  • 同步结果先在本页预览，点击「保存设置」后才用于剪藏；同步不会修改飞书表格。

「可直接复制提示词」「风格码」为带 AI 配置的文本字段，「工作台分类」为单选字段，由飞书侧处理，插件不填写。「标题」「内容」为文本，「链接」为链接字段，「封面」为附件，由插件按剪藏内容填写。

成品视频：支持网页中可直接读取的 MP4 视频，提供预览和来源选择。勾选「同时保存视频」后，可保存到任意分类；目标子表需有「视频」附件字段，也兼容「成品视频」「参考视频」。视频与封面分开保存，单个视频最多 30MB，超过 20MB 自动分片上传。

候选图片可横向浏览，不会向下挤占提示词区域。「上一步」可返回编辑，Esc 或右上角 × 可收起浮层；在同一页面再次点击插件图标会保留草稿。刷新、跳转网页会结束当前草稿。浏览器设置页等受限页面无法打开浮层，请在普通网页使用。

03

连接飞书

使用你的企业自建应用。

凭据仅保存在本机浏览器中，用于连接飞书。

在 飞书开放平台 ↗ 创建企业自建应用，开通 bitable:app、bitable:app:readonly、drive:file:upload 三个权限并发布版本；逐步图文指引见「01 配置指南」。

04

分类与模型

三级分类体系，决定剪藏时可选什么、写到哪里。

本地规则匹配，不调用模型接口、不分析图片或视频；明确的分类会预先选好，手动改过的分类会保留。

读取各绑定子表的风格与模型选项（只读，不修改飞书表格）。先保存「02 收藏位置」与「03 飞书连接」再同步；飞书表格的选项更新后，再同步一次即可。

05

桌面端软件

配套桌面应用「提示词助手」：本插件负责“存”，它负责“用”——在电脑桌面随手复制已剪藏的提示词。

浏览器剪藏插件（存：网页上的提示词 / 图片 / 视频一键写入多维表） → 飞书多维表（数据中台） → 提示词助手（用：托盘速查、一键复制、封面与视频预览）
  1. 下载安装「提示词助手」（Windows / Mac 见上方链接）。
  2. 首次打开：设置 → 数据源 → 环境自检 →「一键自动配置」，自动安装 lark-cli 并引导登录飞书，无需装 Node。
  3. 把本页「02 收藏位置」里同一个多维表副本链接，粘贴到助手的 设置 → 数据源 → 解析 → 立即同步；表名含「提示词」的数据表会自动接入，无需手工配表。
  4. 日常使用：右键托盘图标弹出常用提示词菜单，点击即复制；左键托盘或屏幕右缘悬浮把手展开面板，支持搜索、按分类筛选、★ 设为常用。

剪藏写入哪张表，助手就同步哪张表——在浏览器里收藏灵感，回桌面随手取用。
